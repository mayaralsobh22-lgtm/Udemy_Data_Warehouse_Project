# Udemy Data Warehouse Project

## Project Overview

This project focuses on building a data warehouse for Udemy course data. It includes data integration, ETL processes, schema matching, schema mapping, Star Schema design, and SQL analytics.

## Objectives

- Integrate multiple data sources
- Clean and transform data
- Design a Star Schema
- Load data into a warehouse
- Analyze business insights using SQL
